# Meyammai Jambulingam — Portfolio

Personal portfolio site, built with [Jekyll](https://jekyllrb.com/).

**Live site:** https://purplelitemij.github.io

## Local development

```bash
bundle install
npm ci
bundle exec jekyll serve
```

The site is served at `http://localhost:4000`.

## Deployment

Pushes to `main` are built and deployed to GitHub Pages automatically via
[`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).
